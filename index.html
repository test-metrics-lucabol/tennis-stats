MPTS 2.0 Flow

Record the most important momentum inflection, not every technical detail. Each point uses the same four taps: Momentum, Shot, Detail, then Outcome.

StepQuestion
1Why did the point pivot? GOOD, BAD, QUAL, or N/A.
2Which shot or phase caused the pivot?
3What specific acronym explains it?
4Did our player win or lose the point?

Momentum

CodeMeaning
GOOD (+)We took control or successfully neutralized pressure.
BAD (-)We surrendered control or made a tactical/technical error.
QUAL (!)Opponent won with quality; no obvious correction for our player.
N/A (Ø)Routine exchange; no clear pivot before the terminal result.

Shots

CodeMeaning
SRVServe
RETReturn
FHForehand
BHBackhand
TRNTransition / approach / mid-court entry
NETVolley, overhead, or net finish

SRV appears only when our player is serving; RET appears only when the opponent is serving.

Detail Code Definitions

CodeMeaningUsed for

Terminal details such as ACE, DF, and clear misses record the obvious outcome automatically instead of showing WIN/LOSS.

Automatic Context

This is a player-centric coaching tracker, not a full symmetric match charting system. Capture the most actionable reason the point changed.

ContextHow it works
ServerChoose the first server once. The app alternates by game; use Srv only to correct the current game.
Serve usedUse the 1st/2nd toggle before recording a point. It resets to 1st after each point; second serves are shown as 2nd on the sheet.
Shot filterThe shot screen uses the server context to hide impossible SRV/RET choices.
PressureBreak, game, set, match, deuce, and advantage tags are computed automatically from the score.
*Still manual: use it for emotional or momentum points that matter beyond the formal score.

Stats Rule

The Stats screen flags Lucky Wins, Quality Losses, and the top Shot Leak, then turns the leak into one pattern and one training action.

Post-Match Rule

Review only: One pattern + one action.

PatternAction
Many -BH-SHT lossesTrain backhand cross-court depth with margin
Many -SRV-DF pointsSimplify second-serve target and build spin margin
Many -TRN-CHO pointsAdd a go/no-go cue before moving forward
Many ! pointsDo not over-coach; no clear player correction
