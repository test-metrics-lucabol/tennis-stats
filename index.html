Automatic Context

This is a player-centric coaching tracker, not a full symmetric match charting system. Capture the most actionable reason the point changed.

ContextHow it works
ServerChoose the first server once. The app alternates by game; use Swap Server only to correct the current game.
PressureBreak, game, set, match, deuce, and advantage tags are computed automatically from the score.
*Still manual: use it for emotional or momentum points that matter beyond the formal score.

Recording Priority (during match)

  1. Serve
  2. Return
  3. +1 shot
  4. Short balls given away
  5. Wrong tactical choices
  6. Good neutralizers
  7. Weapons / winners

Do not try to capture everything. Capture the useful coaching signal.
